### Mortgage Calculator (Express + EJS)

Completed:
- Built a full-stack mortgage calculator using Node.js and Express
- Handled form submissions using Express routes and body-parser
- Implemented mortgage calculation logic on the server side
- Used EJS for server-side rendering and dynamic UI updates
- Passed calculated values from backend to frontend templates
- Connected the application to a PostgreSQL database using pg
- Structured the project with separate views, public assets, and server logic
- Styled the application using custom CSS for a clean, user-friendly layout
- Practiced running and debugging a local Express server

Key Takeaway:
Server-side rendering with Express and EJS helps build dynamic applications where logic and UI work together. Handling calculations on the backend improves control, security, and real-world application structure.
